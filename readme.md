# ND1 評価課題01：ブロック崩し

Unreal Engine 5.8 で制作した、2 レベル構成のブロック崩しです。`ND1_2026_10.uproject` を開いて Play すると、タイトル画面から始まります。

## 操作

| キー | 操作 |
| --- | --- |
| A / D、← / → | パドルを左右に移動 |
| Space | タイトルから開始、ボールを発射、Game Over 後に再開、クリア後に次のレベルへ進む |

## 評価項目への対応

- ブロックをすべて壊すと Game Clear、残りのボールを失うと Game Over を表示します。
- Game Over 画面では文字が脈動し、再開案内が明滅します。Space で残数をリセットして同じレベルから再開できます。
- Game Clear 画面には次のレベルへの案内を表示し、Space でレベルを切り替えます。
- ブロックは耐久値を数字で表示し、残り耐久値に応じて色を変えます。
- BGM と衝突 SE を実装しています。音源は `Scripts/generate_audio.py` で作成したオリジナルの WAV です。
- ボールがパドルの中心から離れた位置に当たるほど、反射方向が左右に変わります。
- ブロックから落ちる緑色のアイテムをパドルで取ると、ボールが追加されます。複数のボールがある間は、1 個を失ってもプレイを継続します。
- レベル遷移時には、残数と画面上にあるボールの数を次のレベルへ引き継ぎます。

## アレンジした箇所

- `TitleLevel` に専用のタイトル画面を設けました。
- `Level1` と `Level2` でブロックの配置と耐久値の組み合わせを変えました。
- 耐久値の高いブロックを色で見分けられるようにし、HUD にボール残数を表示しました。
- 追加ボールのアイテムとマルチボールを設けました。
- Game Over と Game Clear の画面にアニメーションを付け、次の操作を画面内に表示しました。
- BGM と SE の音源をプロジェクト内のスクリプトで生成しました。

## 実行とパッケージ化

1. Windows の Unreal Engine 5.8 で `ND1_2026_10.uproject` を開きます。
2. `TitleLevel` から Play します。既定の起動マップも `TitleLevel` に設定済みです。
3. 配布用には Windows / Shipping でパッケージ化します。パッケージ対象のマップは `TitleLevel`、`Level1`、`Level2` に設定済みです。

`McpAutomationBridge` は Editor 専用プラグインです。パッケージ版のゲームには必要ありません。
